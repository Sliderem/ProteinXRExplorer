# ProteinXRExplorer

ProteinXRExplorer is a static Vite, TypeScript, and Three.js application for desktop 3D, VR, and MR. The local Python pipeline generates protein assets served from `web/public/`. Scene 1 ships with ovalbumin (P01012).

- Read [README.md](README.md) for setup, tests, status, and roadmap.
- Read [docs/architecture.md](docs/architecture.md) for the pipeline and viewer modules.
- Use [docs/deployment.md](docs/deployment.md) for the existing Vercel production project, release commands, and verification.
- See [.kiro/specs/scene1-mvp/spec.md](.kiro/specs/scene1-mvp/spec.md) for the original MVP scope.
